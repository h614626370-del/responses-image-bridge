# Product

## Register

product

## Users

Operators configuring a local image-generation bridge for ecommerce clients.
They need Chinese controls for routing, concurrency, failures and upstream account diagnosis.

## Product Purpose

Provide SSE-facing, synchronous-upstream image generation and a private operational console.
Keep client credentials, management credentials and upstream admin credentials separate.
Show verified runtime state, not fabricated compatibility or inferred account assignments.

## Brand Personality

Restrained, precise, dependable.

## Anti-references

No marketing landing page, decorative dashboard cards, giant headings, gradient backgrounds or animated ornaments.
Use ordinary operational forms, tables and status indicators.

## Design Principles

- Put current work and failure states ahead of presentation.
- Make credential changes deliberate and keep secrets out of API responses.
- Prefer read-only account diagnosis; never silently modify upstream accounts.
- Expose the distinction between mock tests and actual customer compatibility.

## Accessibility & Inclusion

Keyboard-operable forms, visible focus rings, explicit labels, text statuses alongside color,
responsive structure and reduced-motion support.
